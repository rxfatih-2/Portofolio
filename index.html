PROFIL & DOKTRIN DESAIN

Struktur Kode Bersih dengan Karakter Visual Kuat.

Saya M Rizki Akbar, pengembang web di balik RXFatih. Setiap karya dirancang dari nol agar memiliki identitas visual yang tegas—memadukan gerbang pembuka animasi, integrasi audio latar otomatis, tata letak presisi di layar ponsel, serta kode HTML, CSS, dan JavaScript yang ringan.

JUTSU // 01

Undangan Pernikahan Digital Kustom

Mengadaptasi kekayaan budaya Nusantara (Sunda, Bugis, Minangkabau) hingga konsep gim interaktif (Pokémon & Super Mario) lengkap dengan hitung mundur, galeri, audio latar, dan konfirmasi WhatsApp.

JUTSU // 02

Website Korporat & Perayaan Perusahaan

Merancang halaman profil dan situs peringatan hari jadi perusahaan dengan hierarki informasi yang tajam, lini masa pencapaian, dan kontras layar optimal.

JUTSU // 03

Permainan & Aplikasi Web Berbasis Browser

Membangun logika permainan papan seperti catur menggunakan JavaScript murni tanpa ketergantungan framework berat sehingga berjalan mulus di berbagai perangkat.
